# Azure Bay Hotel — Website Prototype

## Overview
Built a responsive hotel booking website as part of a team of 4. The site features a price calculator, login page with validation, and an interactive news section.

## My Role
**Front-End Developer (25% contribution)**

- Built the Rooms page
- Built the Gallery page
- Implemented the CSS and JavaScript for both pages
- Focused on responsive layout and cross-device usability

## Technologies Used
- Bootstrap 5
- jQuery
- JavaScript
- HTML5
- CSS3

## Features Built by the Team
- **Price Check Calculator** — Calculates cost based on number of guests and nights stayed, with real-time updates
- **Login Page** — Form validation, "Remember Me" and "Forgot Password" features
- **News Page** — Interactive grid with expandable "Read More" articles
- **Rooms Page** — Detailed room displays with responsive images
- **Gallery Page** — Image showcase with responsive layout
- **Reviews Page** — Customer testimonials
- **Contact Page** — Enquiry form

## Design Approach
- Mobile-first responsive layout using Bootstrap grid
- Clear visual hierarchy with consistent spacing
- Responsive form fields that stack vertically on mobile
- Accessibility considerations across all screen sizes
